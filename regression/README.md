# SQLcl Regression Tests

Automated checks for known SQLcl Project bugs and enhancement requests, run against any installed SQLcl version. Each run produces a PASS/FAIL table, and the expected result for every issue depends on the version: a fixed bug that fails again is reported as a **regression**, and an open bug that suddenly passes as **newly fixed**.

Latest results: [results/README.md](results/README.md).

All tests at a glance: [tests.md](tests.md).

> **Test environments only.** The test project drops and recreates its schema, APEX workspace and ORDS definitions on every run, and creates the schema with a password that is published in its files. Use a local database such as the Oracle Database Free VM, never a production database or one reachable from outside.

## How it works

- [tests.json](tests.json) lists the issues (readable version: [tests.md](tests.md), generated by [catalog.sh](catalog.sh)): severity, area, the SQLcl versions where each was introduced and fixed, links to the forum post and documentation, the workaround, and how to test it.
- `issues/<id>/test.sh` checks one issue using only documented SQLcl commands.
- [reset/](reset/) puts the test project back to its tagged baseline: git, then `drop_all.sql` and `install.sql`.
- [run.sh](run.sh) resets the test project and database, runs the tests in order (export, then stage), and writes `results/<version>/`.
- [report.sh](report.sh) combines all versions into [results/README.md](results/README.md).

## Running it

You need bash (Git Bash on Windows), git, jq, SQLcl 26.1 or later, a local database you may rebuild, and the test project (a SQLcl Project repository with schema DEMO1, an APEX application and an ORDS module; its README explains the two saved connections it needs).

```shell
cp regression/config.example.sh regression/config.sh   # then edit it
bash regression/run.sh 26.2          # all active tests against SQLcl 26.2
bash regression/run.sh 26.2 004 007  # selected tests
bash regression/report.sh
```

With Claude Code, the `sqlcl-regression` skill ([.claude/skills/sqlcl-regression/SKILL.md](../.claude/skills/sqlcl-regression/SKILL.md)) drives the whole loop: runs a version, interprets the outcomes, updates the catalogue, writes new tests, and builds reports.
